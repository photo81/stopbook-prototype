레벨 관리 관리자 레벨별 접근 가능한 메뉴를 지정합니다. 계정은 계정 관리에서 등록합니다.

적용 전 설정 구글 로그인 연동 전이라 여기서 정한 레벨 권한과 '사용 안 함'은 아직 관리자 화면 접근에 적용되지 않습니다.
지금은 누구나 모든 관리자 메뉴를 볼 수 있습니다. 사내 구글 계정 로그인을 연동하면 등록된 사용 중 계정만 로그인하고, 지정한 레벨의 메뉴만 열리게 됩니다.
관리자 레벨 · 수정 버튼(또는 레벨명)을 누르면 이름과 접근 메뉴를 수정할 수 있습니다. 계정이 지정된 레벨은 삭제할 수 없습니다.
레벨명접근 메뉴접근 카테고리계정설명관리
레벨별 접근 메뉴 한눈에 보기 · 대시보드는 모든 레벨이 볼 수 있고, 상세 화면은 목록 화면의 권한을 따릅니다.
