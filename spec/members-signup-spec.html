  2. 회원 생성: 번호 = 최대+1, 등급 '일반', 구분 기본, 아이디 = 이메일
  3. 가입 마일리지 지급 (기본 "회원가입 적립" 2,000P)
  4. "신규가입 10% 할인" 쿠폰 1장 발급
  5. 약관 동의 내역·혜택 지급을 히스토리에 기록
  6. 가입 환영 메일 발송 기록 → ③ 가입 완료 (로그인 상태)
